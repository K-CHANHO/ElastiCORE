# Code of Conduct

ElastiCORE follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, critique code and ideas rather than
people, and help newcomers - many users of a code generator are reading generated
code in a language or framework they are still learning.

## Reporting

If you experience or witness unacceptable behaviour, report it privately to the
maintainers through GitHub's private vulnerability reporting channel
(**Security → Report a vulnerability**) with "Code of Conduct" in the title, or
by contacting a maintainer directly. Reports are handled confidentially; the
enforcement guidelines are those of the Contributor Covenant 2.1.
