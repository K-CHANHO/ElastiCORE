The first release candidate of 3.0.

An AI agent was asked to build the same requirement (a library: books, members, loans) with ElastiCORE, and the places where Java had to be written by hand were recorded. The DSL now covers them. A project that does not use the new syntax generates what it did before. The 2.x generator's output and the `jpa-springboot` bundle are unchanged: `elcoreRulesCheck -Pstrict` reports 150 MATCH / 0 DIFF / 2 ACCEPTED, and `elcoreTreeCheck` reports 0 differ / 0 missing / 0 extra.

### New features

- **`@readonly` on a field:** a value the server decides. The v3 mapper does not copy it from the request.
- **`@search(isnull)`:** search by whether a value is empty.
- **Sign-in API:** `@signin` on an entity line generates sign-in, sign-out and "who am I". It applies to an entity with a `@login` and a `@password` field, one per application. Only the owner or an administrator can change the password or the login.
- **Hand-written refusals are translated** by message code. `PortCallException` answers 502 when a called system fails.
- **TypeScript client with the build:** `elasticore { typescriptClient = true }`.

### Improvements

- **Error responses**
  - A command the lifecycle refuses answers 409; a row the request points at that does not exist answers 404.
  - `ConflictException` lets hand-written rules answer 409 with their own message.
  - Requests Spring MVC refuses before the controller get the same body, with a `code`.
  - One response is in one language: `spring.web.locale` by default, never the server machine's language.
- **DDD bundles** check that referenced rows exist before saving (`requireReferences`), and refuse with 404.
- **Build stops on unreadable models:** a model file that does not parse (`LOAD ERROR`) fails `elcore3`.
- **Search:** in v3, `@search(like)` ignores case.
- **Write path:** `PUT /batch` calls `update(dto)` for each row.
- **Ossie:** `count(Entity)` says which dataset it counts.
- **Warnings:** each DSL warning appears once per run.

### Bug fixes

- **Validation**
  - `@pattern` generates a `@Pattern` that compiles, and takes a message after the value like `@min`.
  - A required relation (`post: Post!`) is required in a save request by its key field.
  - A `@minsize(1)` collection that is not sent at all answers 400.
- **Generated code**
  - `@default(now)` on a `timestamp` field writes `Instant.now()`.
  - The columns of a value object that an entity holds optionally allow NULL.
  - `@restExclude` no longer breaks a hexagonal build, a `@readonly` owner field keeps its owner, and `@updatable(false)` on a reference works.
  - `@rollup` discriminator values match 2.x.
- **Ossie:** expressions are exported as `OSSIE_SQL_2026`, and a subquery `@formula` as `ANSI_SQL`.
- **Runtime**
  - The port registrar scans the package of the class annotated `@EnableElastiCore`.
  - A 2.x application's component scan no longer picks up the API error handler.
  - A `@Primary` bean wrapping a port proxy works again.
- **Review fixes** cover sign-in through another entity's `@ref` or a cascaded row, inherited reference checks, the domain order of reference checks, and value objects from other domains.
