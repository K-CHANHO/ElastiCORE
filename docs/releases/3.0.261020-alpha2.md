The second alpha of 3.0.

### Bug fixes

- A domain with an entity named `Comment` compiles: Hibernate's `@Comment` is written in full where the names collide.

### Improvements

- CI checks that the 2.x reference tree stays exactly as committed.
- The README's quick start is generated by a test, so the steps it shows are known to work.

### Documentation

- **README**
  - The quick start follows the real order of work, and its `build.gradle` works as written.
  - The introduction is aimed at business systems that live for years, with the evidence and the current status.
- **Support:** 3.0 is supported for three years from its first stable release. The policy says which Spring Boot versions fixes target, that releases go through pull requests, and when the signing key expires.
- **Compatibility check:** the check against 2.x is described as it is actually done, not as "byte for byte".
